## 3. Genel mimari

Proje Pot fork'udur: Tauri 1.8 / Rust, React 18 JSX, NextUI, Vite 5, pnpm. Bu Next.js/FastAPI projesi değildir. `.cursor/rules` içindeki genel teknoloji şablonları gerçek mimariyi değiştirme gerekçesi değildir.

Masaüstü uygulaması aynı kalır; ana çalışma arayüzü tarayıcıya taşınır. Rust işlemi bilgisayarda çalışır, `127.0.0.1` üzerinde rastgele portlu yerel HTTP sunucusu açar. Tepsiden web arayüzü yeniden açılabilir. Her açılışta üretilen erişim anahtarı URL fragment'inde gelir; API Bearer doğrulaması ve Host/Origin kontrolü yapar. Bu sürüm internete deploy edilen, masaüstü altyapısı olmadan çalışan bir SaaS değildir. Ekran yakalama, sistem sesi, yerel dosyalar, SQLite ve kısayollar için yerel Rust işlemi gereklidir.

Eski `web-ui/` arayüzü Gemini ağırlıklı ve özellikçe eksikti. Son yaklaşım **mevcut masaüstü React ekranlarının ve servis modüllerinin tamamını yeniden kullanmaktır**. Kopya bir çeviri motoru yazılmadı. Yeni ana giriş `workspace.html`; eski arayüz `/quick` yolunda korunur.

Akış:

```text
Tarayıcı workspace.html
  -> src/browser/bootstrap.js: Tauri IPC uyarlaması
  -> doğrulanmış /api/bridge, /api/bridge/events
  -> Rust web_bridge.rs
  -> görünmez bridge.html Tauri penceresi
  -> src/browser/worker.js: gerçek Tauri invoke/listen
  -> mevcut Rust komutları / Tauri plugin'leri
  -> callback/olay kuyruğu üzerinden tarayıcı
```

Gizli worker ayrı `web-worker` WebView2 profilindedir. Eski daemon'un `--disable-web-security` seçenekleriyle aynı profili paylaşmak `ERROR_INVALID_STATE` oluşturuyordu. Ayrı profil bu nedenle gereklidir; geri kaldırma.

## 4. Kaynak haritası ve yapılan değişiklikler

### Tarayıcı çalışma alanı

- `workspace.html`, `bridge.html`, `vite.config.js`: çok girişli build; browser bootstrap ana uygulamadan önce yüklenir.
- `src/browser/Workspace.jsx`, `workspace.css`: sol menüyle metin, OCR, PDF/EPUB, ses/video/altyazı, servisler/eklentiler, terim sözlüğü, geçmiş, genel/çeviri/OCR ayarları, kısayol, yedekleme, hakkında ve güncelleyici ekranları.
- Mevcut `src/window/*` bileşenleri doğrudan kullanılıyor. Metin/OCR/belge/medya ekranları ziyaret sonrası mounted kalır; ekran değişince devam eden iş kaybolmaz. Ayar/geçmiş ekranları tekrar açılınca remount olur ve güncel veriyi yükler.
- `tt:active-view` olayı metin ve OCR ekranında servis ayarlarını/eklenti listesini yeniler. Bu davranış son eklemelerdendir, gerçek UI kontrolü gerekiyor.
- Tarayıcıdan görsel seçme/pano görseli alma, native bölge seçme düğmesi ve belge/medya sürükle-bırak eklendi. Native dosya seçme/kaydetme diyalogları mevcut ekranlarda çalışmaya devam eder.
- `src/App.jsx`, `src/main.jsx`, `src/components/WindowControl/index.jsx`: tarayıcı shell seçimi, native pencere kontrollerini tarayıcıda gizleme, tarayıcı kısayol/contextmenu davranışları.

### IPC ve ağ

- `src/browser/bootstrap.js`: sessionStorage token, fake Tauri window metadata, callback eşlemesi, 100 ms görünür / 1 s gizli poll, hata/yeniden bağlanma bildirimi, pencere işlemlerini browser'a uyarlama. Native boyutlandırma/pinleme browser chrome tarafından yönetildiği için no-op. `live_caption` gerçek native pencereye yönlendirilir.
- Dosya-drop listener'ları kaydedildikleri sayfayla eşleşir; arka planda mounted belge ve medya ekranının aynı dosyaya birlikte tepki vermesi engellenir.
- `src/browser/worker.js`: callback ID dönüşümü, Event listener'ları, fs-watch sahipliği ve disconnect temizliği; belge/medya/layout/live iş sahipliği. Aynı global native işi iki sekmenin sessizce birbirini iptal ederek çalıştırması engellenir.
- **Kritik düzeltilmiş hata:** `web_bridge_publish` Rust argümanı `callback_id`, JS argümanı `callbackId` olmalı. `callback` ve `error` Tauri'nin ayrılmış IPC alanlarıdır; bunları normal invoke argümanı olarak kullanmak bütün cevapları kaybettiriyordu. Bu düzeltme gerçek entegrasyon testinde doğrulandı.
- `src-tauri/src/web_bridge.rs`: komut allowlist'i, sekme oturumları, callback/event kuyruğu, polling acknowledgement, 45 s bağlantı watchdog, native eylem ve image import komutları. Sekme başına 256 pending komut, 8192 olay/64 MB kuyruk, en çok 8 sekme.
- `src/browser/fetch.js`, `src-tauri/src/web_fetch.rs`: dış HTTP fetch çağrılarını native reqwest üzerinden gerçek ReadableStream'e çevirir; SSE parçaları, HTTP hata durumları, AbortSignal ve native iptal korunur. Aynı origin istekleri orijinal browser fetch kullanır. İstek sınırı 32 MB, cevap 64 MB, timeout 300 s; 32 aktif istek sınırı.
- `src/browser/fetch.test.js`: 5 test; yerel fetch, streaming, başlık sonrası iptal, başlık/ack öncesi iptal, HTTP 429.

### Yerel web sunucusu

- `src-tauri/src/web_ui.rs`: yeni Vite assets'i app asset resolver ile sunar; eski quick API'leri korur. **Asset path başındaki `/` gereklidir**; aksi halde Tauri ilk karakteri atıp index fallback verir. Bu hata düzeltildi ve entry/assets testi geçti.
- `/api/session` yalnız `/api/asset` yoluna HttpOnly SameSiteStrict cookie verir. Görsel endpoint'i canonical path ile app config/cache altındaki görselleri sunar.
- `/api/bridge/upload` tarayıcı dosyasını app-cache `browser-uploads/<client>/<uuid>-<filename>` altına stream eder; 2 GB sınırı. Native dosya seçme bu kopyalamayı gerektirmez.
- Son değişiklik HTTP sunucusuna 8 bounded worker thread ekledi; büyük upload sırasında event polling engellenmesin. Derlendi ve son entegrasyon bu build üzerinde geçti. Çoklu büyük dosya/sessiz kopma senaryosunu ayrıca dene.
- Debug build'e özel `TURKTRANSLATE_TEST_URL_FILE` ve `TURKTRANSLATE_TEST_NO_OPEN=1` ortam değişkenleri otomasyon içindir; release'de etkin değildir. Token dosyasını commit etme.
- CSP mevcut eklenti `eval` kodu ve OCR WASM ihtiyacını korur. Keyfi internet sitesine sunucuyu açma veya auth kontrollerini kaldırma.

### Paylaşılan işlev düzeltmeleri

- `src/hooks/useConfig.jsx`: store.set/save/emit sıralaması await edilir; async transport üzerinde ayar kaybını önler.
- `src/hooks/useVoice.jsx`: AudioContext kullanım sırasında oluşturulur/resume edilir; oynatma bitişindeki node referansı yarış durumu düzeltilir.
- `src/utils/history.js`: paylaşılan SQLite bağlantısı, `CREATE TABLE IF NOT EXISTS`, concurrent insert güvenliği. Bir motorun geçmişe yazdıktan sonra diğer motorun bağlantısını kapatması kaldırıldı.
- `src/window/Config/pages/History/index.jsx`: ilk kullanım şema kurulumu; geçmişi temizlerken tabloyu drop etmek yerine satırlar silinir.
- `src/utils/history.test.js`: eşzamanlı yazma ve başarısız başlangıç sonrası tekrar deneme.
- `src-tauri/src/window.rs`: tray/global hotkey/yerel API ile gelen çeviri veya OCR eylemleri aktif tarayıcıya yönlenir; browser yoksa eski native fallback sürer. Ekran alanı seçim overlay'i native kalır.

### Önceki ajanlardan taşınan önemli kaynaklar

- `src-tauri/src/document/`: native PDF export, layout preservation, image OCR/çeviri, canonical/lossless layout, Unicode/form text, EPUB, Rust document translation pipeline.
- `src-tauri/src/media.rs`, `media/`: medya transkripsiyonu ve sistem sesi/canlı altyazı.
- `src/window/Document`, `Subtitle`, `LiveCaption`: mevcut zengin iş akışları; bunları sade Gemini-only formuna dönüştürme.
- `src/services/translate/index.jsx`: 21 çeviri sağlayıcısı; OCR barrel'ında 15 servis; ayrıca TTS, collection (Anki/Eudic), `.potext` eklentileri.
- `src-tauri/assets/fonts/DejaVuSans.ttf`: native PDF export için gerekli, commit'e dahildir.
- `.scripts/`: eski PDF/OCR inceleme scriptleri korunur. Bir kısmı eski makinedeki gerçek belge yollarını kullanır; hepsini otomatik çalıştırma. Yeni taşınabilir sentetik testler aşağıdadır.

## 6. Yeni bilgisayarda başlatma

Windows tercih edilir; global shortcut, ekran görüntüsü ve sistem sesi burada denenmelidir. Git, Rust stable MSVC toolchain, Visual Studio C++ build tools/Windows SDK, Node/pnpm ve WebView2 Runtime gerekir. `.node-version` tarihsel olarak `21` diyor; son test makinesinde Node `26.13.0` kullanıldı. Node sürümünü sırf bu not nedeniyle değiştirme; mevcut lockfile ile install/build/test sonucunu esas al. Mevcut pnpm script ve dependency sürümlerini koru.

```powershell
git clone https://github.com/dragolitor-star/pot-desktop.git
cd pot-desktop
pnpm install --frozen-lockfile
pnpm test
pnpm build
cargo test --manifest-path src-tauri/Cargo.toml
```

Cargo PATH'te değilse kendi makinenin `.cargo/bin` yolunu ekle. Eski bilgisayarın `C:\Users\Dell` yollarını yeni makineye kopyalama.

Normal geliştirme: `pnpm tauri dev`. Önceki ortamda sandbox'ta başlayan Vite sunucusuna sandbox dışı native app erişemedi; worker hazır olmadı. Bu **uygulama mantığı hatası gibi ele alınmamalı**. Aynı ağ/izin bağlamında başlat veya aşağıdaki gömülü asset build'ini kullan. Gömülü build ile gerçek entegrasyon geçti.

### Deterministik gömülü arayüz testi

```powershell
pnpm build
```

12. `docs/web-ui.md` ve `ARCHITECTURE.md` artık yeni workspace'e yönlendirilmiştir, ancak özelliklerin gerçekten doğrulandığı matrisi tamamla. Eski `NEXT-AGENT.md` ayrıntılarını silmeden güncel durumu üstten açıkla.
13. Son kaynakta `pnpm test`, `pnpm build`, `cargo test`, gerçek bridge entegrasyonu çalıştır. Gereksiz test tekrarları yerine değişen risklere odaklan.
14. `pnpm tauri build --bundles nsis` ile **yeni** installer üret; `src-tauri/target/release/bundle/nsis/` altındaki zaman/sürümün bu kaynakla eşleştiğini doğrula. Eski installer'ı teslim etme.
15. Üretim binary'sini başlatıp gömülü workspace, önemli akışlar ve kapanışı kontrol et. Masaüstü özellik matrisi tamamlanmadan “tüm özellikler tam çalışıyor” deme. Somut doğrulanmış sonuçları ve kalan dış hesap/ortam bağımlılıklarını dürüstçe belirt.

## 8. Beklenen tamamlanma ölçütü
